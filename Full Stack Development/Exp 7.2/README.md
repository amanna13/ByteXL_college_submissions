## Title
Implement Redux Toolkit for State Management in Shopping Cart

## Objective
Learn how to use Redux Toolkit to manage global application state in a React project, focusing on implementing a shopping cart. This task helps you understand slices, actions, reducers, and connecting React components to a Redux store efficiently using modern Redux Toolkit practices.

## Task Description
Create a React application that displays a list of products, allowing users to add products to a shopping cart. Use Redux Toolkit to manage the cart state globally by creating a slice that defines actions for adding items, removing items, and updating quantities. Create a cart component that displays the items currently in the cart, including their name, price, and quantity. Connect the components to the Redux store using react-redux hooks such as useSelector and useDispatch to handle state updates. Test the app by adding, updating, and removing products and verify that the cart state updates correctly and reflects changes in the UI immediately.
